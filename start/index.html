설치 방법

쓰는 휴대폰을 고르세요. 처음 한 번만 하면 돼요.

1단계30초

홈 화면에 Trova 추가하기

  1. Safari에서 Trova 열기꼭 Safari로 열어 주세요. 인스타·카톡 안에서 열면 홈 화면에 추가가 안 돼요.
  2. 아래 ⋯→공유
  3. 더 보기→홈 화면에 추가→추가‘웹 앱으로 열기’는 켜 둔 채로 두세요.
  4. 홈 화면 아이콘으로 열고 로그인카카오나 구글 계정으로 바로 시작해요.
Safari에서 Trova 열기

주소 app.trovapp.workers.dev

2단계한 번만

공유 단축어 연결하기

아이폰은 홈 화면 앱이 공유 목록에 바로 뜨지 않아요. ‘Trova에 저장’ 단축어를 한 번 연결해 두면 공유 버튼만으로 저장돼요.

  1. Trova에서 마이페이지→아이폰 공유 단축어홈 첫 화면의 ‘아이폰 공유 단축어 받기’로도 갈 수 있어요.
  2. 키 받기→키 복사하기키는 내 단축어에만 저장돼요. 다른 사람에게 보여 주지 마세요.
  3. 단축어 받기→다운로드Safari 주소창 왼쪽 ⤓ → 다운로드 → ‘Trova에 저장’을 눌러요.
  4. 단축어 설정→붙여넣기→단축어 추가빈칸을 누르면 ‘붙여넣기’가 떠요.
3단계이제부터 매번

여행 영상 공유하기

  1. 인스타·유튜브 영상에서 공유앱에서는 공유 → ‘더 보기’ 또는 ‘공유…’를 누르면 목록이 나와요.
  2. Trova에 저장 누르기처음 한 번은 연결·알림을 물어요. ‘항상 허용’과 ‘허용’을 눌러 주세요.
  3. ‘Trova에 보냈어요’ 알림이 뜨면 끝잠시 뒤 Trova를 열면 장소와 준비된 일정이 있어요.
1단계30초

Trova 설치하기

  1. Play 스토어에서 ‘Trova’ 설치지금은 출시 준비 중이에요. 올라오면 아래 버튼으로 바로 갈 수 있어요.
  2. 지금 바로 쓰려면 Chrome으로 열기오른쪽 위 ⋮ → 홈 화면에 추가 또는 앱 설치를 누르면 앱처럼 쓸 수 있어요.
  3. Trova를 열고 로그인카카오나 구글 계정으로 바로 시작해요.
Chrome에서 Trova 열기 Play 스토어 · 출시 준비 중

주소 app.trovapp.workers.dev

2단계이제부터 매번

여행 영상 공유하기

안드로이드는 공유 목록에 Trova가 바로 보여서 단축어를 연결할 필요가 없어요.

  1. 유튜브·인스타 영상에서 공유목록에 없으면 ‘더보기’를 눌러요.
  2. 공유 목록에서 Trova 누르기바로 분석이 시작돼요. 다른 앱으로 가도 계속돼요.
  3. 장소와 일정 확인영상 속 장소가 지도에 담기고, 준비된 일정을 바로 여행으로 만들 수 있어요.
